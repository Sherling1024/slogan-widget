# 桌面标语小部件 · Slogan Widget

一块常驻桌面的置顶小卡片：轮播「学习 / 工作」标语催你动手，每专注 45 分钟提醒你起来休息。

![预览](preview.png)

## 启动

| 方式 | 操作 |
| --- | --- |
| 推荐 | 双击 `启动标语小部件.vbs`（静默启动，不闪黑框） |
| 备选 | 右键 `SloganWidget.ps1` →「使用 PowerShell 运行」 |
| 命令行 | `powershell -ExecutionPolicy Bypass -File SloganWidget.ps1` |

如果双击 VBS 没反应（个别安全软件会拦脚本宿主），直接用「备选」方式启动即可，效果一样。

第一次启动会出现在屏幕右下角，之后自动记住位置与大小（写入 `config.json`）。

## 交互

- **拖动** —— 移动位置，松手即记住
- **双击** —— 立刻换一句
- **右键** —— 菜单：今日任务… / 下一句 / 暂停轮播 / 今日口号 ▸ / 大小 ▸ / 始终置顶 / 开机自启 / 退出

界面只保留一个状态点、一句标语和一条进度细线，没有计时数字、没有时钟、没有操作提示。

## 大小与字号

默认是「自适应文字」：卡片宽高跟着当前这句标语自动计算，短句小、长句大，始终留出同样的内边距。

右键 →「大小」里可以改成固定档位，或直接调字号（字号变化后仍按新字号自适应）：

| 菜单项 | 效果 |
| --- | --- |
| 自适应文字 | 回到自动计算（默认） |
| 小 / 中 / 大 | 240×88、300×104、380×126（逻辑像素，随系统缩放） |
| 字号 + / 字号 − | 11–30 之间加减 1 |

卡片尺寸会在 190×72 ~ 620×260 之间夹取，并且始终落在屏幕工作区内；靠近屏幕右半边时会以右边缘为锚点缩放，不会跑出屏幕。

## 今日口号（联网推荐）

右键 →「今日口号」切换标语来源：

| 菜单项 | 说明 |
| --- | --- |
| 使用默认口号 | 用脚本内置的标语库（默认） |
| 使用今日推荐 | 从「一言」取一句文学/诗词短句，当天就用这一句 |
| 换一条推荐 | 立刻再取一条，取到后淡入显示 |

- 只取 8–26 字的句子，长句自动折成两行，卡片宽度跟着自适应
- 推荐结果缓存在 `config.json` 的 `todayQuote` / `todayQuoteDay`：当天再次启动直接复用，跨天自动刷新
- 联网失败不影响使用，静默退回内置文案，不会弹窗打扰
- 只请求 `https://v1.hitokoto.cn`，不上传任何本机信息

## 每日任务

右键 →「今日任务…」打开清单窗口：

- 勾选 / 取消勾选**即时写回**，没有单独的「保存」按钮
- 底部输入框回车（或点「添加」）新增一条；选中后按 `Delete` 删除
- 标题下方显示当天进度 `已完成 n/总数`
- 想直接打开清单，也可以带参数启动：`powershell -ExecutionPolicy Bypass -File SloganWidget.ps1 -OpenTasks`

数据文件是同目录的 **`tasks.json`**（已加入 `.gitignore`，不会提交到仓库），按日期分组：

```json
{
  "2026-11-08": [
    { "text": "看完 HH-D02 手册第 1-5 页", "done": true },
    { "text": "跑通 SLE 收发例程", "done": false }
  ]
}
```

每天第一次打开会新建当天分组，历史日期原样保留，可以随时回看或手改这个文件。

## 它显示什么

- 左上小圆点：蓝 = 学习，紫 = 工作，绿 = 休息
- 中间：标语，每 22.5 分钟淡入淡出换一句；每 4 句会穿插一句休息提醒（「今日口号 → 使用今日推荐」时，改显示当天推荐的那一句）
- 每专注 45 分钟，自动进入休息提醒（默认 270 秒）：卡片文字与圆点变绿
- 底部细线：本轮进度，休息时倒着走

## 开机自启

右键菜单勾选「开机自启」即可（在系统启动文件夹里放一个指向本目录的快捷方式），取消勾选即删除。
命令行也可以：

```
powershell -ExecutionPolicy Bypass -File SloganWidget.ps1 -InstallAutostart
```

## 自定义

用 VS Code / PowerShell ISE 打开 `SloganWidget.ps1`（**保持 UTF-8 带 BOM**，否则中文会乱码）：

- **改文案**：`$quotesStudy` / `$quotesWork` / `$quotesRest` 三个数组，`|` 表示换行
- **改节奏**：`FocusTarget = 2700`（45 分钟一轮）、`RestTotal = 270`（休息 270 秒）、`$script:RotTimer.Interval = 1350000`（22.5 分钟换一句）
- **改字号**：`FontPx = 19.0`（9–30）
- **改配色**：`Accents` 里的 `study` / `work` / `rest` 三个颜色

## 说明

- 只用系统自带的 Windows PowerShell 5.1，**不需要安装任何依赖**
- 自动适配屏幕缩放（本机 3200×2000 @200% 已适配）
- 只允许单实例，重复启动会自动退出
- 出问题看 `widget.log`；加 `-Trace` 参数运行会额外写 `_trace.txt`
